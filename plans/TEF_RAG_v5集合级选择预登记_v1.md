# TEF-RAG v5 集合级选择预登记 v1

登记时点：2026-09-14。此文档在任何 v5 新数据生成、holdout 排名或 gold 评分之前创建。既有复杂链 v8 永久作为事后诊断开发集，不再用于调参后优势验证，也不运行 v5 的报告分数。

## 方法冻结项

- 独立实现路径：`tef_rag_v5/`；不覆盖 v1-v4、旧实验、旧数据或失败记录。
- 候选范围：沿用 v4 的同资产且 `event_time <= query_time`、`available_at <= query_time`；所有对比方法共享同一候选 ID 集合。
- Top-k：主结果固定为 5；另可做预先声明的 k=1/3/5 预算曲线，但不得用曲线选择方法参数。
- 集合目标权重：语义 0.45、有向链覆盖 0.25、新角色覆盖 0.20、冗余惩罚 0.10。
- beam width=64；集合每层只增加一个节点；字符预算默认 16000；所有并列按记录 ID 和真实加入序列确定性打破。
- 链端点相关性门控下限固定为 0.20；链类型以指数饱和；角色以概率覆盖；冗余以 `top_k` 最大成对数归一化。
- Query profile 只能读取查询文本和查询元数据；记录角色只能读取单条公开记录；关系与冗余投影只能读取公开候选记录或其通用表示。均不得读取 gold、必要组、问题答案、案例评分或人工事件图。
- 若使用现有 LLM 配置，先固定提示词和输入输出 schema，再生成唯一缓存；报告调用次数与缓存响应 token usage，不输出密钥。401/402/403 时停止新增调用并保留失败。

## 可证伪机制假设

H1（查询条件化）：在候选、语义分数和关系图相同而 query profile 不同的最小合成例中，最终集合应随证据角色/关系需求改变；若不改变，query conditioning 没有实际进入选择。

H2（集合边际增益）：加入已经覆盖的角色或高度冗余记录，其边际收益应低于加入仍被需求但未覆盖的角色；若相反，角色覆盖或冗余项实现失败。

H3（有向更新链）：只有两个端点都实际入选且边满足对应时间方向时才获得链收益；反向边必须拒绝。若单独端点或被拒绝边获得链收益，实现失败。

H4（Top-k 截断）：当高质量更新位于旧式长路径末端且只剩一个槽位时，v5 必须按该节点对当前集合的真实边际收益判断，不能因路径前缀占位而自动丢弃。此假设以不读 gold 的合成契约测试检验。

H5（trace 一致性）：`trace` 长度必须等于实际返回数；第 i 步 `selected_id` 必须等于第 i 个 `evidence_id`；`set_after` 必须精确等于当时前缀；记录的激活边两端必须都在该前缀。任何不一致均为实现失败。

## 开发门槛

先写并通过单元测试与一个不读 gold 的最小合成烟测，覆盖 H1-H5、预算、可见性与确定性。开发烟测只验证机制，不报告 Recall/nDCG，不据烟测输出调整冻结权重。完成后运行全量测试与旧 freeze 校验；不运行封存的旧 98 题。

## 可选新 holdout 协议

仅在上述门槛通过后，才生成约 4 个全新案例。每案预期包含复杂过程题、截止敏感题和最近状态对照；候选链的长度与干扰来自合理运维过程，不为压低基线添加失真噪声。先只做以下审计并提交用户人工可读审查：

1. 与既有案例/记录 ID 及原文的结构隔离检查；
2. 双时间、工单、关系方向、候选可见性和自然性审计；
3. 每题在共享候选范围下确有可回答证据，且候选数足以形成真实选择压力；
4. 不运行任何方法排名，不读取聚合检索成绩。

只有用户确认后才能冻结并排名。TEF-v5、TA-RAG、TG-RAG、scoped Hybrid、scoped Latest 必须逐题共享完全相同的候选范围和 Top-5；不得减少基线候选、槽位或可见信息。

## 预登记评价与判定

若 holdout 获准冻结，主要描述指标为复杂过程题的 Group Recall@5 与 binary nDCG@5；Complete@5 保留为严格次要指标，并明确其地板效应。截止敏感题和 latest-control 分层单列。样本约 4 案，只报告逐题和描述性配对差值，不做显著性或总体外推。

相对 scoped Hybrid 的机制支持条件预先定义为：复杂过程题平均 Group Recall@5 严格更高，且逐题胜数多于负数，同时 latest-control 不出现必要证据召回下降。任一条件不满足，只能记为无优势或负面结果；不得修改权重/profile/gold 后继续把同一 holdout 当独立验证。TA/TG 的兼容限制继续原样披露。

本轮不评价最终回答生成，不修改论文，不扩展到旧 98 题或大规模实验。
