# TEF-RAG data

This directory contains the public retrieval and structured-generation benchmarks used in the paper.

- retrieval/ contains the temporal evidence benchmark, released test evaluator, and published retrieval predictions.
- generation/ contains structured work-order/action-plan reference outputs, indexes, and normalization metadata.

The benchmark is public-source-grounded and AI-assisted synthetic data. It is intended for controlled comparison of retrieval and generation methods, not as a record of real station failure frequencies or field-certified procedures.
