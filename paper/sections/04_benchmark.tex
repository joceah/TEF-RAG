\subsection{时序运维 Benchmark}
\label{sec:dataset}

本文构建 TEF-RAG v6 Semantic Benchmark v1，用于受控评价动态运维场景中的时序证据检索。该 benchmark 属于 \emph{public-source-grounded, AI-assisted synthetic benchmark}，并非真实电站故障日志或领域专家人工标注数据。公开产品资料与研究数据只用于约束电芯类别、物理范围和采样背景；具体运维事件链、诊断演化、规程情境与查询任务由受控的 AI-assisted 语义生成流程构造。其目标是系统控制晚到记录、版本替换、跨来源互补证据和持续不确定性等因素，并观察不同检索方法对这些因素的处理能力。

数据组织层次如表~\ref{tab:dataset_structure}。每条 chain 表示一个完整运维过程，由多条 evidence records 构成；每条 chain 派生多个不同任务意图，每个意图再生成语义保持的 paraphrase。检索 gold 以“必要证据组 + 必要 flow edges”表示，因此评价的不是某一条唯一文本，而是一个任务是否获得了足以形成完整流程的证据集合。

整个 benchmark 包含 400 条 authored chains、3888 条 evidence records、1200 个 primary intents 和 2400 条 query rows。开发、验证与测试按 chain 划分，从而避免同一事件过程的 paraphrase 跨 split。两类难度各包含 200 条 chain：Realistic Distribution Set 覆盖较常见的时序组合；Temporal-Hard Challenge Set 则强化晚到证据、supersession、跨 episode 混淆和跨来源互补证据。

\subsection{结构化生成评价}

为检验检索优势能否传递到下游任务，我们在同一批 authored chains 上建立结构化 generation gold。该 gold 同样是 \emph{AI-assisted adjudicated synthetic gold}，而非领域专家人工 gold：多个生成/复核结果经过一致性检查与分歧裁决后形成最终结构化参考。每个 primary intent 对应一个语义 gold object，并由其两个 paraphrases 共享。因此 development/validation/test 分别包含 720/240/240 个 semantic gold objects，对应 1440/480/480 条 queries。

每个输出由两部分组成：标准化工单 \texttt{work\_order} 与动作计划 \texttt{action\_plan}。工单描述诊断、推荐动作、适用规程、验证/不确定性状态及证据引用；动作计划由原子动作及其依赖关系构成。该评价关注“检索到的上下文是否足以支持更准确的结构化输出”，而不把语言模型本身作为本文的主要算法贡献。

\subsection{对比方法}
\label{sec:baselines}

为保证比较只反映检索策略差异，所有方法首先使用相同的合法证据快照：仅保留目标资产中满足
$t_e(e)\le t_q$、$t_a(e)\le t_q$ 的记录，并对规程证据施加相同的版本有效期、撤回状态与型号适用性约束。
在此基础上比较以下五种方法，所有方法的最终检索预算均为至多 5 条证据。

\textbf{BM25。}
采用标准 BM25 作为词法检索基线~\cite{robertson2009bm25}，
在每个查询对应的合法证据快照上独立建立索引，
参数固定为 $k_1=1.5$、$b=0.75$，并直接返回得分最高的 5 条证据。

\textbf{BGE Reranker。}
首先使用与上述相同的 BM25 检索 Top-30 候选，
随后使用 \texttt{BAAI/bge-reranker-v2-m3} 对
$(\text{query},\text{evidence})$ 文本对重新计算相关性分数~\cite{chen2024bgem3}，
并按照重排分数选取前 5 条证据。
该基线用于比较通用语义重排是否能够弥补纯词法检索的不足。

\textbf{Temporal-BM25。}
该基线在 BM25 相关性之外显式加入时间匹配项。其排序分数为
\begin{equation}
s_{\mathrm{TBM25}}(e,q)
=
\lambda\,\widetilde{s}_{\mathrm{BM25}}(e,q)
+
(1-\lambda)\,s_{\mathrm{time}}(e,q),
\end{equation}
其中 $\widetilde{s}_{\mathrm{BM25}}$ 为归一化 BM25 分数，
$s_{\mathrm{time}}$ 根据查询中的年份、时间区间、before/after 以及 current/latest 等时间表达，
计算证据事件时间与目标时间的匹配程度。
对于没有显式时间意图的查询，时间项设为常数，因此保持原 BM25 排序。
我们仅在最终测试前的参数选择阶段比较 $\lambda\in\{0.25,0.50,0.75\}$，
并冻结表现最好的 $\lambda=0.25$ 用于后续评价。

\textbf{TA-RAG。}
采用 Lau 等人提出的 Time-Aware RAG~\cite{lau2025tarag}。
该方法首先从查询中分解主题与目标时间范围，
再利用时间区间过滤限制候选文档，并在时间候选上执行语义检索与 BGE 重排。
为适配本文的离散运维事件，每条证据的 \texttt{event\_time}
被映射为长度 1 秒的半开时间区间，查询中的相对时间均以 $t_q$ 为参考时刻；
此外，TA-RAG 的索引只在当前查询的合法证据快照上构建，
从而避免未来记录影响检索。
除 LLM 后端替换为固定的 DeepSeek 模型外，其时间分解、区间过滤、
Nomic embedding、FAISS 检索与 BGE reranking 流程保持与公开实现一致。

\textbf{TEF-RAG。}
本文方法在同一合法证据快照上进一步进行学习式证据对筛选、
查询条件化关系建图以及集合级非线性排序，
最终返回整体证据流得分最高的候选集合。

\subsection{评价指标}
\label{sec:metrics}

\textbf{Retrieval。}
使用 Recall@5 与 nDCG@5 衡量传统相关性；Complete@5 要求结果至少覆盖每个必要证据组；FlowComplete@5 在此基础上进一步要求存在全局一致的组--证据赋值，使必要 flow edges 同时得到满足。后两项直接衡量本文关注的集合级完整性。

\textbf{Generation。}
正文报告四项主要指标：Field Macro F1 (strict)、Action F1、Citation F1 与 Plan EM (strict)。它们分别衡量工单关键字段、规范化动作、claim--evidence 引用以及完整动作计划的严格匹配。其余 schema validity、dependency/order 与 end-to-end exact match 用于诊断。

\subsection{消融设置}

为分析最终性能来自哪些组成部分，我们在 480 条 validation queries 上执行四组冻结消融：去除 learned pair proposal、去除 relation-graph-derived set features、去除 hard-negative mining，以及去除 nonlinear set ranker。完整模型与各变体保持相同的 Top-30 搜索池、pair budget、relation prompt/threshold 和候选集合定义；其中 graph-feature ablation 只移除关系图派生的集合特征并重新训练相同 RankNet，hard-negative ablation 只保留第一轮训练，nonlinear-ranker ablation 则回退到冻结的 Stage-3A 选择结果。消融不进行新的超参数搜索，也不运行新的 test prediction 或读取 test gold，因此只用于组件归因，不用于重新选择最终测试配置。

\subsection{实验控制}

Retrieval 的开发、验证和最终测试严格分离；所有模型选择与训练只使用 development/validation 信息，最终 test 在配置冻结后用于一次性评价。Generation comparison 固定使用同一个下游生成器、同一 prompt/schema 与解码设置，只改变输入的检索证据。这样可以把下游生成差异解释为检索上下文质量的变化，而不是生成模型配置差异。
