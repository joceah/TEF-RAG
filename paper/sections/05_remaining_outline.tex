\subsection{检索主结果}

表~\ref{tab:retrieval_results} 给出 test split 上的检索结果。
TEF-RAG 在 Recall@5、nDCG@5、Complete@5 与 FlowComplete@5 四项主指标上均取得最高值。
相较于这些指标上最强的非 TEF baseline（均为 Temporal-BM25），
TEF-RAG 的 Recall@5 从 0.4591 提升至 0.7228，nDCG@5 从 0.4955 提升至 0.6231；
更明显的差异出现在集合级完整性：Complete@5 从 0.0792 提升至 0.3188，FlowComplete@5 从 0.0792 提升至 0.3146。
这说明仅加入时间偏好能够改善单条证据召回，但显式建模 evidence-flow 关系并联合选择证据集合，对恢复完整任务支持结构更为关键。

\subsection{Validation 消融实验}
\label{sec:ablation_results}

表~\ref{tab:ablation_results} 给出 validation split 上的四组消融结果。完整 TEF-RAG 的 FlowComplete@5 为 0.4042；去除 learned pair proposal 后仅下降至 0.4021，说明在固定 pair budget 下，proposal 对最终质量的直接贡献较小，其主要价值是把关系判断集中到更有希望的 pair。相比之下，去除 relation-graph-derived features 后 FlowComplete@5 降至 0.3667，说明集合排序确实利用了图结构信息。

影响更明显的是训练目标与排序器本身。去除 hard-negative mining 后 FlowComplete@5 从 0.4042 降至 0.2833；去除 nonlinear set ranker、回退到 Stage-3A 选择器后降至 0.3125。这表明，最终性能并非仅来自候选召回或额外关系判断，而主要依赖对“高相关但流程不完整”集合的显式困难负例学习，以及非线性的集合级排序能力。值得注意的是，去除 nonlinear ranker 时 nDCG@5 略高于完整模型（0.6965 vs. 0.6885），但 Complete@5 和 FlowComplete@5 明显更低，进一步说明本文方法优化的是集合流程完整性，而不只是传统单条相关性排序。

\subsection{下游结构化生成结果}
\label{sec:generation_results}

表~\ref{tab:generation_results} 只保留最能回答“更好的 evidence flow 是否改善最终工单与动作计划”的四项生成指标。
在相同 generator、prompt、schema 与 decoding 设置下，TEF-RAG 在四项指标上均取得最高值：
Field Macro F1 为 0.5345，Action F1 为 0.2035，Citation F1 为 0.1585，Plan EM (strict) 为 0.0417。
相较各指标上最强的非 TEF baseline，Action F1、Citation F1 与 Plan EM 分别取得约 24.3\%、26.9\% 与 121.8\% 的相对提升；Field Macro F1 相较 Temporal-BM25 提升约 2.4\%。
结果表明，TEF-RAG 的收益不仅体现在上游检索命中率，也能够传递到工单关键字段、处置动作和证据引用质量。
TEF-RAG 提高了生成工单的字段级准确性、动作正确性和计划级一致性。

\subsection{进一步分析}

TEF-RAG 并非在所有生成诊断指标上都占优。
例如，TA-RAG 的 Dependency F1 为 0.3271、Order Validity 为 0.4125，均高于 TEF-RAG 的 0.2858 与 0.3146。
这一现象表明，evidence-flow retrieval 更直接改善的是“提供哪些事实和动作依据”，而动作之间的全局依赖与执行顺序仍受到下游 planner/generator 本身能力的限制。
换言之，上游证据组织已经显著改善 factual grounding 与 action fidelity，但尚不足以单独解决完整的全局计划组合问题。

% =========================================================
\section{局限性与有效性威胁}
\label{sec:limitations}
% =========================================================

本文 benchmark 是 public-source-grounded、AI-assisted synthetic benchmark，而非真实电站工单或领域专家标注数据；
因此其主要价值是受控比较 temporal evidence retrieval 机制，不能直接外推到真实电站故障频率或机器人现场安全性。
生成评价虽然覆盖字段、动作、依赖与引用，但没有模拟实际机器人执行、环境反馈和安全联锁。

% =========================================================
\section{结论}
\label{sec:conclusion}
% =========================================================

本文提出 TEF-RAG，将动态运维 RAG 的检索目标从独立文档相关性扩展为查询时刻可见、关系一致且流程完整的 Temporal Evidence Flow。
在冻结的 temporal-hard benchmark 上，TEF-RAG 在 Recall@5、nDCG@5、Complete@5 与 FlowComplete@5 上均超过四种对比方法；
在固定下游生成器的结构化 generation test 中，TEF-RAG 同时取得最高的字段级匹配、Action F1、Citation F1 与 strict Plan EM。
这些结果说明，面向证据集合及其时序关系的检索能够改善进入生成器的任务支持上下文，并进一步提高工单字段、维护动作与证据引用的准确性。
后续工作需要进一步结合显式计划与执行约束。
